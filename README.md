# 🛡️ AI Fact-Checker (ระบบวิเคราะห์และเปรียบเทียบความน่าเชื่อถือของข่าวออนไลน์)

ระบบตรวจสอบความน่าเชื่อถือของข่าว ข่าวลือ หรือเนื้อหาบนโลกออนไลน์ โครงงานนี้ใช้สถาปัตยกรรมการประมวลผลแบบ **Fast & High-Yield Comparative RAG** ซึ่งผสานการทำงานของการสกัดเนื้อหาเว็บ (Web Scraping), การสืบค้นและจัดอันดับด้วยตรรกะแบบยืดหยุ่น (Soft-Scoring Search), และการใช้ Large Language Model (LLM) ในการวิเคราะห์เปรียบเทียบข้อมูลเชิงลึก

---

## 🏛️ สถาปัตยกรรมระบบ (System Architecture)

ระบบแบ่งการทำงานออกเป็น 4 ขั้นตอนหลัก เพื่อให้ได้ผลลัพธ์ที่รวดเร็ว แม่นยำ และมีหลักฐานอ้างอิงที่ครอบคลุมที่สุด:

1. **Information Extraction (สกัดข้อมูลต้นทาง):**
   - รองรับการรับข้อมูลทั้งแบบ "ข้อความ (Text)" และ "ลิงก์ (URL)"
   - ทะลวงระบบป้องกันของแพลตฟอร์ม Social Media (Facebook, X, IG, TikTok) และเว็บไซต์ข่าว เพื่อสกัดเนื้อหาที่ซ่อนอยู่

2. **Search Planning (วิเคราะห์และวางแผนสืบค้น):**
   - ใช้ LLM วิเคราะห์ข้อความต้นฉบับ เพื่อสกัดแก่นเรื่อง (Core Keywords), สถานที่ (Locations), และตั้งสมมติฐานปี พ.ศ. (Target Year)
   - สร้างประโยคค้นหาแบบภาษาธรรมชาติเพื่อนำไปใช้สืบค้น

3. **Targeted Fetch & Soft-Gate Reranking (ดึงข้อมูลและจัดอันดับ):**
   - ค้นหาข่าวจาก ฐานข้อมูลเว็บไซต์รัฐบาล (`.go.th`) และ สื่อกระแสหลักที่น่าเชื่อถือ จำนวน 30 ลิงก์ ผ่าน Exa AI
   - **Soft-Scoring Logic:** ใช้ Python ให้คะแนนความเกี่ยวข้อง (สถานที่, แก่นเรื่อง, ไทม์ไลน์) 
   - *จุดเด่น:* ไม่เตะข่าวทิ้งเพียงเพราะไม่มีเลขปี พ.ศ. ในเนื้อหา แต่จะหักคะแนนข่าวที่เก่าเกินไป เพื่อจัดอันดับและคัดเฉพาะ **Top 12 ลิงก์** ที่ดีที่สุดส่งต่อให้ AI

4. **Comparative Analysis (วิเคราะห์และเปรียบเทียบด้วย AI):**
   - LLM นำข้อความต้นฉบับมาเปรียบเทียบกับ 12 แหล่งอ้างอิง
   - **Fair Comparison (Broad-to-Specific):** หากต้นฉบับพูดกว้างๆ แต่อ้างอิงระบุลึกถึงระดับหน่วยย่อย ระบบจะถือว่า "สอดคล้องกัน" โดยไม่หักคะแนน
   - **Yield Maximization:** AI จะรวบรวมและแสดงแหล่งอ้างอิงที่รายงานเหตุการณ์เดียวกันทั้งหมด (5-8 ลิงก์) เพื่อให้ผู้ใช้เห็นหลักฐานที่ชัดเจนที่สุด

## 📂 โครงสร้างไฟล์หลักและหน้าที่ (File Structure)

### 1. `app.py` (หน้าจอผู้ใช้งานและตัวควบคุมหลัก)
- สร้าง Web Application ด้วย **Streamlit**
- จัดการ Cache เพื่อความรวดเร็วในการประมวลผลคำถามที่ซ้ำกัน
- มี User Interface (UI) แสดงผลลัพธ์ในรูปแบบ Truth-O-Meter (คะแนน 10% - 95%) พร้อมสรุปประเด็นที่สอดคล้อง, ประเด็นที่ขัดแย้ง, บทวิเคราะห์เชิงลึก, และรายชื่อแหล่งอ้างอิงที่เกี่ยวข้อง

### 2. `search.py` (ระบบสืบค้นและจัดอันดับข้อมูล)
- เชื่อมต่อกับ **Exa AI API** ในการดึงข้อมูลผ่านเทคนิค Semantic Search
- ใช้การประมวลผลแบบขนาน (Concurrent Futures) เพื่อดึงข้อมูลเว็บรัฐบาลและสื่อกระแสหลักพร้อมกัน
- ทำหน้าที่เป็น **Reranker (ตัวจัดอันดับ)**: คัดกรองและให้คะแนนข่าวจากสถานที่และเวลา โดยผลักดันให้ข่าวที่เกี่ยวข้องกันจริงๆ ทะลุขึ้นมาอยู่ใน Top 12 

### 3. `scraper.py` (ระบบสกัดเนื้อหาจากเว็บไซต์และโซเชียลมีเดีย)
- ทำความสะอาด URL (Clean Mobile URL & Redirects)
- ใช้ **curl_cffi** และ **Jina AI** ในการ Impersonate Browser เพื่อหลบหลีกระบบ Anti-bot ของเว็บไซต์ต่างๆ
- รองรับการสกัดข้อความพรีวิวจาก Facebook (ผ่าน Embed Iframe และ Meta tags), X (Twitter), และ Instagram

### 4. `llm.py` (หัวใจสำคัญในการคิดวิเคราะห์)
- เชื่อมต่อกับโมเดล **Qwen 3 (8B)** (`qwen/qwen3-8b`) หรือโมเดลอื่นๆ (เช่น Llama 3.1, Ministral) ผ่าน OpenRouter API โดยสลับการตั้งค่าในไฟล์ `.env`
- กำหนด Prompt อย่างเข้มงวดให้ AI ทำหน้าที่ 2 ส่วน:
  1. *Search Planner:* วางแผนหา Keyword ก่อนสืบค้น
  2. *Comparative Analyst:* เปรียบเทียบเนื้อหา และสร้างผลลัพธ์ออกเป็นโครงสร้าง **JSON** ที่มีรูปแบบตายตัว (รองรับการฟ้อง Error เมื่อโครงสร้างผิดพลาด)

### 5. ไฟล์การตั้งค่าระบบ
- `.env`: เก็บความลับและ API Keys (`OPENROUTER_API_KEY`, `EXA_API_KEY`, ฯลฯ)
- `requirements.txt`: รายชื่อไลบรารีที่จำเป็น (เช่น `streamlit`, `requests`, `beautifulsoup4`, `curl_cffi`)

## ⚙️ มาตรฐานการให้คะแนน (Truth-O-Meter Logic)

ระบบประเมินความน่าเชื่อถือออกเป็น 5 ระดับ:
*   🟢 **95% (Score 5):** สอดคล้องกับสื่อหลักอย่างสมบูรณ์ (น่าเชื่อถือสูง)
*   🟢 **75% (Score 4):** สอดคล้องส่วนใหญ่ (อาจมีตัวเลข/สถิติคลาดเคลื่อนเล็กน้อย)
*   🟡 **50% (Score 3):** ข้อมูลก้ำกึ่ง / ขัดแย้งบางส่วน
*   🔴 **25% (Score 2):** ข้อมูลบิดเบือน / นำเค้าโครงของข่าวเก่าหรือสถานที่อื่นมาดัดแปลง
*   🔴 **10% (Score 1):** ข่าวขัดแย้ง 100% / ข่าวปลอม / ไร้ข้อมูลอ้างอิงสนับสนุนอย่างสิ้นเชิง
